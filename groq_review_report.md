## src/analysis/grid_trajectory/pet_grid.py

- **Logical Error in `compute_pet` (Case 2 Unreachable):** The condition `elif B.t_exit <= A.t_enter` is logically impossible given the loop structure. Since `sorted_intervals` is sorted by `t_enter` and `j > i`, it is guaranteed that `A.t_enter <= B.t_enter`. Consequently, the "B -> A" direction is never evaluated, leading to missed PET events where the later-entering object exits before the earlier-entering object enters (though this specific geometric overlap is rare in simple sequential cell occupancy, the logic is fundamentally flawed for general interval pairs).

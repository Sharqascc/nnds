# Archived Documentation

These files are historical records of the repository's development. They
contain stale numbers, deprecated paths, and results from earlier
experiments. Do **not** cite them in papers or use them as a reference
for current behavior.

The current canonical documents are in `docs/` (parent directory).
Start with `STATUS.md` for the current state, `MODULE_MANIFEST.md` for
the pipeline definition, and `VALIDATION.md` for what is and is not
verified.

## What is in here

- `CLEANUP_SUMMARY.md` - 2026-05 repository reorganization notes
- `DEBUGGING.md` - legacy Colab-era debugging guide
- `MIGRATION_GUIDE.md` - pre-Phase-2 import path migration
- `PUBLICATION_READINESS.md` - placeholder / incomplete
- `comprehensive_assessment_report.md`, `final_assessment_report.md`,
  `repository_assessment.md`, `repo_full_details.md` - historical
  assessment reports with superseded metrics
- `detection_system_report.md`, `tracking_system_report.md` - early
  module deep-dives, superseded by `MODULE_MANIFEST.md`
- `final_submission_summary.md` - pre-audit event counts

These files are kept for provenance; they are not maintained.

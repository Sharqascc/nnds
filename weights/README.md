# Weights

The UVH-26 checkpoint is expected at:

```text
weights/uvh26.pt
```

## Restore

From a fresh clone, run:

```bash
git lfs install
git lfs pull
```

Or download the checkpoint explicitly:

```bash
bash scripts/download_uvh26.sh
```

## Expected file

- Name: `uvh26.pt`
- Size: `57142241` bytes
